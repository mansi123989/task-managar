🗂️ **TaskFlow — Team Productivity & Habit Manager**

A full-stack task manager web app built during hackathon by a team of three members.

🚀 **Overview**

TaskFlow is a productivity web application designed to help individuals and teams organize tasks, track habits, collaborate efficiently, and monitor daily routines.
It combines a Kanban board, routine manager, team groups, note library, and daily trackers—all in one simple dashboard.

Built with the goal of improving productivity and promoting healthy daily habits.

✨ **Features**

📝 **Routine Manager**


Add daily tasks


Delete tasks


Mark tasks as completed


Simple and clean UI for routine tracking




🧩 **Kanban Board**


Three columns: To-Do, In Progress, and Done


Drag-and-drop tasks between columns


Add and delete tasks easily


Helps visualize workflow and progress



👥**Team Groups**


Create a new team or join an existing one


Unique team code generated for each group


Share the code via email to invite members


Enables collaboration for team projects or study groups



📚 **Library**


Add personal notes or thoughts


Save and access ideas anytime


 Read/generate new thoughts 



📊**Daily Tracker**

Track:


Sleep hours


Phone usage


Mood levels


Visual representation:


All tracked data is displayed as graphs for better analysis and habit improvement
